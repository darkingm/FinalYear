# Cryptocurrency Logos

- https://cryptologos.cc/
- https://icons8.com/icons/set/cryptocurrency

Required coins:
- btc.png (Bitcoin)
- eth.png (Ethereum)
- bnb.png (Binance Coin)
- usdt.png (Tether)
- usdc.png (USD Coin)
- dai.png (DAI)
- matic.png (Polygon)
- arb.png (Arbitrum)
- link.png (Chainlink)
- uni.png (Uniswap)
- aave.png (Aave)
- wbtc.png (Wrapped Bitcoin)
- weth.png (Wrapped Ethereum)
- placeholder.png (Fallback image)

Recommended size: 128x128px PNG with transparent background
