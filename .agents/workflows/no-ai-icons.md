# Rule: No AI-Generated Icons or Images

Always use real, authentic icons and images. Never use AI-generated or placeholder icons.

## Coin / Token Logos
- Use `getCoinLogo(symbol)` from `@/lib/utils/coin-logos` — returns real logos from CoinCap CDN
- Use `<img src={getCoinLogo(sym)} ... />` with `onError` fallback (hide on fail)
- Do NOT use Next.js `<Image>` for external CDN coin logos (domain whitelist required)
- Primary CDN: `assets.coincap.io/assets/icons/{symbol}@2x.png`
- Fallback CDN: `cryptologos.cc/logos/...`

## Framework Icons (UI)
- Use **lucide-react** for all UI icons (arrows, checkmarks, cart, wallet, etc.)
- Lucide icon components: `<ArrowLeft />`, `<CheckCircle />`, `<ShoppingCart />`, etc.
- Do NOT render SVG paths manually for icons that lucide provides
- Do NOT use emoji as icons in production UI

## What NOT to do
- ❌ Do NOT use `<svg>` paths you wrote/generated yourself for crypto logos
- ❌ Do NOT use base64-encoded "icons" generated by AI
- ❌ Do NOT use placeholder.svg for coins — use getCoinLogo() instead
- ❌ Do NOT use `<Image>` from next/image for external CDN logos without domain config
- ❌ Do NOT use emoji (🟡 🔷) as visual icons in cards/badges

## Adding a new coin
1. Add it to `COIN_LOGOS` in `frontend/lib/utils/coin-logos.ts`
2. Find logo at: `https://assets.coincap.io/assets/icons/{symbol_lowercase}@2x.png`
3. Always include `onError` handler to hide broken images gracefully
